# Обновленный пример ячейки "LLM graded answer"

## Новая структура

Теперь используется структура с двумя типами разделителей:

1. **Вопрос** (видим студенту): между `### BEGIN QUESTION_LLM` и `### END QUESTION_LLM`
2. **Критерии оценки** (скрыты, используются LLM): между `### BEGIN CRITERIA_LLM` и `### END CRITERIA_LLM`

## Пример 1: Простой вопрос

**Тип ячейки:** Markdown, "LLM graded answer"  
**ID:** `recursion_question`  
**Points:** 10

**Содержимое ячейки в source версии:**

```markdown
### BEGIN QUESTION_LLM
Объясните, что такое рекурсия в программировании. Приведите пример рекурсивной функции.
### END QUESTION_LLM

### BEGIN CRITERIA_LLM
Критерии оценки:
- 10 баллов: Полное объяснение с правильным примером рекурсивной функции
- 7 баллов: Хорошее объяснение, но пример неполный или неточный
- 4 балла: Частичное понимание концепции, пример отсутствует или неправильный
- 0 баллов: Неправильный ответ или отсутствие ответа
### END CRITERIA_LLM
```

**Примечание:** Разделители можно писать с префиксом `###` или без него. Оба варианта работают:
- `### BEGIN QUESTION_LLM` 
- `BEGIN QUESTION_LLM`

**Что видит студент после `nbgrader generate_assignment`:**

```markdown
Объясните, что такое рекурсия в программировании. Приведите пример рекурсивной функции.

YOUR ANSWER HERE
```

## Пример 2: Вопрос с анализом кода

**Тип ячейки:** Markdown, "LLM graded answer"  
**ID:** `code_analysis_1`  
**Points:** 15

**Содержимое ячейки:**

```markdown
### BEGIN QUESTION_LLM
Проанализируйте следующий код и объясните его работу:

```python
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n-1)
```
### END QUESTION_LLM

### BEGIN CRITERIA_LLM
Детальные критерии оценки (максимум 15 баллов):

1. Идентификация функции (5 баллов):
   - Правильно названа функция: 5 баллов
   - Частично правильная идентификация: 2-3 балла
   - Неправильная идентификация: 0 баллов

2. Понимание рекурсии (6 баллов):
   - Объяснена рекурсивная структура: 3 балла
   - Упомянут базовый случай (n == 0): 2 балла
   - Объяснено, как работает рекурсивный вызов: 1 балл

3. Примеры и применение (4 балла):
   - Приведен пример работы функции: 2 балла
   - Объяснено, когда использовать рекурсию: 2 балла

Штрафы:
- -2 балла за каждую существенную ошибку
- 0 баллов, если ответ не по теме или копипаста без понимания
### END CRITERIA_LLM
```

## Пример 3: Вопрос без явных разделителей (обратная совместимость)

Если разделители `BEGIN QUESTION_LLM` не используются, весь контент до `BEGIN CRITERIA_LLM` будет считаться вопросом:

```markdown
Объясните концепцию объектно-ориентированного программирования.

### BEGIN CRITERIA_LLM
Оценка:
- 10 баллов: Полное объяснение с примерами
- 5 баллов: Частичное объяснение
- 0 баллов: Неправильный ответ
### END CRITERIA_LLM
```

**Что видит студент:**

```markdown
Объясните концепцию объектно-ориентированного программирования.

YOUR ANSWER HERE
```

## Настройка разделителей в nbgrader_config.py

```python
c = get_config()

# Настройка разделителей для LLM ячеек
# Общая настройка для LLMGrade, ClearLLMAnswers, ClearLLMCriteria
c.LLMDelimiterConfig.begin_question_delimiter = 'BEGIN QUESTION_LLM'
c.LLMDelimiterConfig.end_question_delimiter = 'END QUESTION_LLM'
c.LLMDelimiterConfig.begin_criteria_delimiter = 'BEGIN CRITERIA_LLM'
c.LLMDelimiterConfig.end_criteria_delimiter = 'END CRITERIA_LLM'

# Старые per-class параметры тоже работают и имеют приоритет
# c.LLMGrade.begin_question_delimiter = 'BEGIN QUESTION_LLM'
# c.ClearLLMCriteria.begin_criteria_delimiter = 'BEGIN CRITERIA_LLM'
```

## Важные замечания

1. Разделители должны быть на отдельных строках
2. Вопрос остается видимым студенту после `generate_assignment`
3. Критерии полностью удаляются из студенческой версии
4. После вопроса автоматически добавляется "YOUR ANSWER HERE"
5. Можно использовать markdown форматирование в вопросе
